# kellyfitzgerald.me

Plain static site: no build step. Open `index.html` in a browser to preview.

- `index.html`: home (hero, scope, case study list, about, writing, contact)
- `work/*.html`: the four case studies
- `assets/style.css`: all styling, light and dark mode

To publish, upload the whole folder to any static host (Netlify, Cloudflare Pages, GitHub Pages) and point kellyfitzgerald.me at it.

Contact links (LinkedIn, email) are in the contact section of `index.html`.
